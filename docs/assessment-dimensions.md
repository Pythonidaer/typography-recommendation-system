# Candidate assessment dimensions

Status: exploratory proposal, version 0.1. No final questionnaire, score formula, or endpoints are approved.

## Start with five independent preferences

| User-facing question draft | Source tag | Intended interpretation |
| --- | --- | --- |
| How calm should the text feel? | /Expressive/Calm | Desired calm appearance |
| How much should the text draw attention? | /Expressive/Loud | Candidate interpretation of loudness, to check with examples |
| How playful should the text feel? | /Expressive/Playful | Desired playfulness |
| How much of a vintage style do you want? | /Expressive/Vintage | Interest in an older visual character |
| How much should it suit a business setting? | /Expressive/Business | Contextual appearance preference, not professional competence |

These questions are proposed language. Their meaning must be compared against actual examples and source labels before scoring. Ask separately for heading and paragraph preferences where useful; people may want an expressive title and restrained paragraphs.

Do not put calm and loud on opposite ends of a single scale. Do not treat business as the opposite of playful. Independent labels can coexist.

An initial answer format could be “not a priority / somewhat / strongly / not sure.” This expresses importance, not an exact desired numeric tag value. An explicit avoidance choice would need separate wording and missing-data behavior; “not a priority” is not dislike. No mapping to numbers is approved.

## Keep practical requirements separate

Family count, reading task, language, required characters, available styles, medium, and existing design belong to the project brief. They are not personality scores. Font category can be an optional preference, with overlapping categories preserved.

Reading needs should use direct questions about text length, size, and conditions. Do not infer them from a “Childlike” or “Easy Reading” tag or a person’s age.

## Missing-data rule for the pilot

A candidate can take part only in comparisons where the required dimensions have adequate comparable evidence. Do not replace absent tags with zeros, averages, or opposites. If that leaves too few candidates, explain the gap or widen research. Do not reward sparse records by averaging only their strongest known traits.

## What remains to test

- Can a beginner understand each question without typography vocabulary?
- Does the source label match the intended user-facing meaning?
- Are the same traits meaningful for headings and body text?
- Does a requested size or weight change the appearance enough to change the answer?
- Can reasons be stated using the evidence rather than fabricated percentages?
